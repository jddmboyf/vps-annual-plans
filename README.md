## 「高性能」在这家身上该怎么理解

先把线路讲清楚，这是最容易买错的地方。RackNerd 不做 CN2，也不做 9929 或 CMIN2 这类国内优化线路，走的是普通国际 BGP。有一份洛杉矶 4GB 特价机的测评给出了三网回程：电信 163、联通 4837、移动 CMI，移动从广州方向还会绕欧洲。三网 TCP 大包延迟电信多在 155 到 195ms，联通 160 到 260ms，移动 170 到 240ms，部分省份有丢包。同机房内网速度能到 800Mbps 左右，连亚洲和欧洲节点单线程在 120 到 200Mbps。

这个线路水平意味着什么：给海外用户建站、跑 API、做落地机、传文件，完全够用；指望国内用户晚高峰秒开，会失望。

CPU 也不是卖点。那份测评的机器是 Xeon Gold 6152 三核，Sysbench 单线程 1124、多线程 3001，Geekbench 5 单核 823、多核 1931。这个分数放在今天属于中低端，跑静态站和轻量服务没问题，跑编译、跑重查询会明显慢。

存储这块要分开看。年付特价和 KVM 月付档标的是 SSD，Ryzen 和 Windows 系列才是 NVMe。同理，SATA 接口的顺序读写理论天花板在 500MB/s 上下，4K 随机 IOPS 通常只有几万；走 PCIe 的 NVMe 顺序读写能到 3500MB/s 级别，4K 随机 IOPS 可以到百万量级。这个差距落到实际使用上，体现在 CMS 后台每次请求要读大量小文件、MySQL 查询的 IO 等待、以及重启后的缓存预热速度。

不过标 SSD 的机器实测数据有点意思：4K Q1 读 21MB/s、写 42MB/s，4K Q32 读 263MB/s、写 166MB/s，1M Q8 读 2.7GB/s、写 1.8GB/s。1M 顺序读超过 SATA 接口的理论上限，说明实际硬件和标称口径未必完全一致，但 4K 随机那一组数字说明它不是高端 NVMe 的表现，跑重数据库别抱期待。
